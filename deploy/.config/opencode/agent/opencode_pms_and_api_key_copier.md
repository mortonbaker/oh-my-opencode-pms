# Opencode PMS and API Key Copier

This agent copies the oh-my-opencode-pms directory and API keys for minimax and xiaomi to morton@learning-machine.

## Capabilities
- Copies the oh-my-opencode-pms directory
- Copies API keys for minimax and xiaomi
- Transfers files to morton@learning-machine

## Usage
When asked to copy opencode-pms and API keys to morton@learning-machine, this agent will:
1. Locate the oh-my-opencode-pms directory
2. Locate the minimax and xiaomi API keys
3. Copy these files to morton@learning-machine using secure transfer methods
